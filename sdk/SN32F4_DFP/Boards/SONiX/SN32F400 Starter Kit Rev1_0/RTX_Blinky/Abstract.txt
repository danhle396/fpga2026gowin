The 'Blinky' project is a simple program for the SONiX 'SN32F769'
microcontroller using SONiX 'SN32F760 Starter Kit' Evaluation Board, compliant 
to Cortex Microcontroller Software Interface Standard (CMSIS v2.0).

Example functionality:
 - Clock Settings:
   - SYSCLK  = 12.00 MHz

The simple RTX Kernel based example simulates the step-motor 
driver. One LED blinks simulating the activation of 
the four output driver stages:


- phase A
- phase B
- phase C
- phase D

This example simulates Half step driver mode and
CW rotation direction.


The BLINKY example program is available for several targets:

  SN32F769 Flash:    runs from Internal Flash located on chip
                    (used for production or target debugging)
